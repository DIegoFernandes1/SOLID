📘 SOLID — Guia Rápido

Este repositório contém exemplos curtos, diretos e práticos de cada princípio do SOLID.
A ideia é simples: bater o olho -> lembrar o conceito -> aplicar no código.


---

🧱 O que é SOLID?

Conjunto de 5 princípios para deixar o código mais organizado, flexível e fácil de manter.


---

📚 Princípios

Princípio	Significado simples	Lembrete rápido	Pasta

S — SRP	Uma classe deve ter uma responsabilidade	[SRP](/01_SRP)

O — OCP	Código deve permitir extensão, sem exigir modificação	[OCP](/02_OCP)

L — LSP	Subclasses devem poder substituir a classe base sem quebrar o sistema		[LSP](/03_LSP)

I — ISP	Interfaces devem ser pequenas e específicas		[ISP](/04_ISP)

D — DIP	Dependa de abstrações, não de implementações concretas	[DIP](/05_DIP)
